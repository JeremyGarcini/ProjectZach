# Persona — the approval moment

A SwiftUI prototype of the instant an ambient AI pauses to ask permission before
acting in someone's life, built at two different stakes:

- **Low** — move a dinner reservation because a meeting is running long.
- **High** — send a message to a real person that commits them to a lease.

Both live on one screen. No backend, no auth, no networking, no dependencies.
Every value is hard-coded.

## Run

1. Open `Persona.xcodeproj` in Xcode 26 or later.
2. Select the **Persona** scheme and an iOS 26 iPhone simulator.
3. Run.

The first high-stakes send fails by design; **Try again** succeeds. The ↺ button
in the header re-arms it.

## What to look at

| | |
| --- | --- |
| **The half-second read** | The request title is the only large thing on the page. |
| **Where the friction is** | Low stakes commit on a tap. High stakes commit on a *held* press, one screen further in. |
| **The progressive blur** | Content dissolves into the pinned header — built from stacked materials, no private API. |
| **The unglamorous states** | In progress with a real Cancel, a deterministic failure, retry, decline, undo. |
| **Colour** | Means outcome only. Never risk. |

## Tests

```sh
xcodebuild test -project Persona.xcodeproj -scheme Persona \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```

8 unit tests over the state machine, 7 UI tests over every state in the script.

The project is generated by XcodeGen from `project.yml`; the generated
`.xcodeproj` is committed so no tooling is needed to open it.
